지원자 처리 지연·누락 방지

지원자 관리에 들어온 담당자가 처리할 지원자를 바로 확인하고 처리하도록 돕는 기능의 디자인 시안입니다. 요약 팝업, 조건 적용 지원자 목록, 리마인드 메일로 구성됩니다.

A안 A안 · 처리 필요 버튼 ‘현재 공고 지원자’ 옆 ‘처리 필요 >’ 버튼으로 요약 팝업을 열어 조건을 고르고, 고른 조건명이 포지션 탭 위에 표시되는 버전입니다. 열기 → B안 B안 · 필터 칩 목록 위 ‘처리 필요 지원자’ 칩 하나로 진입하고, 조건을 고르면 같은 자리가 조건 칩으로 바뀌는 버전입니다. 사용자가 건 정렬·필터만 pill로 보여줍니다. 열기 → C안 C안 · 전체/처리필요 탭 카카오톡 ‘전체/안읽음’처럼 ‘전체 / 처리필요’ 탭으로 나누고, 처리필요 탭에서 조건을 골라 보는 버전입니다. 열기 →
