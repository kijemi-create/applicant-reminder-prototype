시계 아이콘 · 바늘 회전 스펙

조건(리마인드) 필터(BZFliterChip)의 leading 아이콘. XDS biz/clock-fill과 모양이 같고, 원과 바늘만 분리해 바늘이 한 바퀴 돌 수 있게 한 버전입니다.

칩은 왼쪽부터 조건 필터 디폴트 상태 · 조건 필터 조건 1개 적용 상태 · 디폴트 상태 비활성(0명). 비활성은 회색으로 표시하고 회전하지 않습니다.

파일

SVGclock-fill-hand.svg (24×24)
원 .clock-body = fill="currentColor" · 바늘 .clock-hand = mask 안의 구멍(투명)
원본XDS Core biz/clock-fill의 벡터를 그대로 나눔 (모양 · 크기 동일)
바늘을 mask로 둔 이유원본처럼 바늘 자리가 비어 있어야 필터 배경(디폴트 흰색 · 호버 #f4f6f7 · 조건 1개 적용 #eef3ff)이 그대로 비쳐 보입니다. 흰색으로 칠하면 조건 1개 적용 상태에서 바늘만 하얗게 뜹니다.

CSS 예시

.clock-hand {
  transform-origin: 12px 12px;
  transform-box: view-box;
}
.is-spinning .clock-hand {
  animation: clock-hand-spin 1s cubic-bezier(.4, 0, .2, 1) var(--spin-delay, 0s) both;
}
@keyframes clock-hand-spin {
  from { transform: rotate(0deg); }
  to   { transform: rotate(360deg); }
}
@media (prefers-reduced-motion: reduce) {
  .is-spinning .clock-hand { animation: none; }
}

한 화면에 아이콘이 여러 개면 mask id가 겹치지 않게 인스턴스마다 고유 id를 붙여 주세요(React라면 useId()). 다시 돌릴 때는 클래스를 뺐다가 다음 프레임에 다시 붙이면 됩니다.
